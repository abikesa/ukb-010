
# Ukusoma Spiral: Signal Noise Toolkit

This app renders the Five-Glyph cosmology into a symbolic and functional interface.

## Layers

- 🌊 Dopamine (input)
- ❤️ Rules (law)
- 🔁 Game (logic)
- 🐬 Equilibrium (interface)
- 📡 Illusion (deployment)

## How to Run

1. Serve `index.html` via any HTTP server (or deploy to GitHub Pages)
2. For Flask backend, run `flask_api.py`
3. Load `manifest.json` for installability (PWA)
4. Use `sw.js` to cache for offline use
